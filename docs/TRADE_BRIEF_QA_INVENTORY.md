- **Existing evidence reuse:** Prior completed candles supply explicitly labeled ATR14 simple mean, full-day volume ratio and structure distances; same-date macro components support a yield spread. Fixtures check formulas and exclusions.
- **Source integration:** Cached explicit-attribution news and real-only earnings, plus a raw Schwab options sample, either contribute with provenance or explain their gaps. No synthetic substitutes or per-click RSS/calendar fanout.
- **AI control:** Manual click only; strict server snapshot; fixed-text selection; bounded one-attempt cache; no verdict upgrades; rejected output leaves deterministic results.
- **Credit discipline:** Only the isolated worker receives model credentials. Persistent 6/hour and 30/day attempt limits, one active worker request, 350 output tokens, no SDK retries. These are request bounds, not a credit-cost estimate.
- **Presentation:** Calculated findings and coverage reasons visible on desktop and phone; context links usable; no horizontal overflow.
- **Preserved boundaries:** iOS paused, SPY forecasts disabled, no crypto ENTER signals, no new X connection or provider subscription.
